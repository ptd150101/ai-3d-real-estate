# Product brief

## Product goal

Nestora helps home buyers and renters in Vietnam discover, understand and shortlist verified properties. The differentiator is a context-aware assistant paired with an interactive 3D tour rather than a generic chat bubble.

## Primary users

1. Buyers and renters searching by location, price, area and lifestyle constraints.
2. Agents managing listings, appointments and qualified leads.
3. Administrators moderating data, legal documents, media and AI knowledge sources.

## P0 user journeys

- Search in Vietnamese → structured filters → list or map → property detail.
- Open 3D tour → select floor/room → ask the assistant about that room/property.
- Calculate a loan → submit an appointment → follow appointment status.
- Agent creates a draft → uploads media/GLB → adds verified documents → publishes.
- Administrator reviews leads, conversations, appointments and audit history.

## Success metrics

- Search-to-detail click-through rate.
- 3D viewer start and hotspot interaction rate.
- Chat answer completion and human-handoff rate.
- Appointment conversion rate.
- Listing verification freshness and expired-listing rate.
- LCP, error rate and GLB load/failure rate by device class.

## Out of scope for the first production launch

Automatic 3D generation, automated legal validation, legally binding transactions, AI price guarantees and unrestricted autonomous agent actions. Interfaces and flags exist so these can be added without weakening current safeguards.
