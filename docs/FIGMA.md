# Figma handoff

Recommended three-page structure for a Starter plan:

1. `01 — Design System`: colors, typography, spacing, buttons, inputs, cards, chat messages, viewer controls and states.
2. `02 — Public Product`: home, search/list, map search, property detail, 3D viewer, compare, favorites, login and mobile variants.
3. `03 — Admin & Prototype`: dashboard, inventory form, media/3D metadata, appointments, leads, knowledge base and clickable user journey.

The implementation's CSS custom properties in `apps/web/app/globals.css` are the source tokens to mirror in Figma.
