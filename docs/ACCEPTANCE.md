# P0 acceptance checklist

- [x] Responsive home, search, detail, project, agent, auth and administration pages.
- [x] Shareable URL filters, pagination, sorting, list and map views.
- [x] PostgreSQL persistence, Alembic, PostGIS extension/index and pgvector HNSW index.
- [x] Admin CRUD and publish/unpublish workflow.
- [x] Image/GLB upload to local or S3-compatible storage and background job state.
- [x] GLB viewer with lazy start, orbit, reset, fullscreen, floors, furniture, hotspots, quality presets and walk mode.
- [x] Contextual chat, streaming, verified citations, search, compare, nearby, mortgage and handoff tools.
- [x] Favorites, saved-search API, comparison and appointments/leads.
- [x] Authentication, RBAC, rate limits, audit logs and security headers.
- [x] Dynamic metadata, canonical URL, JSON-LD, sitemap and robots.
- [x] Backend tests, browser smoke tests, CI, Docker Compose and backup scripts.

External production services—real legal documents, real GLB assets, email/Zalo, CRM and a chosen LLM provider—require credentials and business agreements. Their adapters and integration points are present; no fake third-party delivery is claimed.
